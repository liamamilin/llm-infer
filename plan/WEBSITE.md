# 学习网站设计与信息架构

## 技术方案

使用 VitePress **稳定版 1.6.4**（不用 alpha），Node.js 22+，Markdown + Vue 组件，内置本地搜索与 GitHub Pages。首轮使用稳定、少依赖的默认主题做出好看的站点，必要时才自定义组件和设计系统。

## 站点首页

- 一句话价值：小模型贯穿全程，把模型文件变成稳定推理服务。
- 两个主入口：「开始实践」「查看课程地图」。
- 进度说明：验证已通过/待实测，不虚构全书完成。
- 学习路径：基础→测量→优化→部署。
- 静态交互演示：从 Token 到输出（明确标注教学模拟）。

## 导航

顶部：开始学习、课程、图解、术语、GitHub；侧边栏按章节显示。正文设置目录、跨章节前后导航，代码可复制，注意字号与表格横向滚动。

## 设计风格

定位：工程书籍/技术实验室，不是 SaaS 产品广告。配色克制，轻柔背景，标题层级清晰，中文/英文/代码混排容易辨认；深浅模式可用。优先原生可访问性及响应式行为。

## 站点验收

1. 本机 `npm run docs:build` 通过，无死链。
2. `npm run docs:dev` 启动，浏览器在桌面和手机视口检查首页/章节/互动组件。
3. 每页一级标题正确、图片带 alt、交互按钮可以键盘操作。
4. 真正验证内容与页面状态对应；不能将 placeholder 链接当正式功能。

站点只承载静态内容和浏览器内的轻量交互。若未来提供线上模型 API 调用，需要另建独立后端和费用控制，绝不可直接把模型 API 密钥放在 GitHub Pages 前端。
