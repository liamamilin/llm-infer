# 目录 + 案例矩阵

每章围绕同一个主线小模型推进，新增实验只引入必要的新能力。

| 章 | 核心问题 | 最小必须交付的实战案例 | 推荐视觉 |
|---|---|---|---|
| 00 环境与首次推理 | 如何在给定设备跑起一个模型？ | 实机诊断、模型加载、生成 1+ token | 整体推理路径图 |
| 01 模型资产 | 模型“文件”里到底有什么？ | 读取权重目录、config、tokenizer、revision | 模型资产拆解图 |
| 02 Token 到输出 | 一次推理怎么发生？ | 编码、Prefill/Decode 概念映射、逐 token 生成 | token 交互演示 |
| 03 生成控制 | 如何改变输出行为？ | temperature/top-p/max_tokens/stop 对照 | 参数交互卡片 |
| 04 HTTP & Streaming | 怎样被应用调用？ | 起服务、curl/Python 客户端、SSE 流式响应 | 请求时序图 |
| 05 基准测试 | TTFT 等指标如何公平测？ | 预热、重复、记录数据、可视化 | 瀑布图/延迟分解 |
| 06 内存与 KV Cache | 显存和上下文有什么关系？ | 采样内存、变上下文、对照缓存 | 内存构成示意 |
| 07 量化 | 哪些情况下值得量化？ | 支持的两种精度比较（或硬件限定案例） | 内存/性能对照图 |
| 08 Prefix Caching | 如何加速重复前缀？ | 重复/不重复前缀对照（支持的引擎） | 前缀共享图 |
| 09 Batching / 并发 | 单请求与高并发有何不同？ | 1/2/4+ 并发压测与失败率 | 吞吐-延迟曲线 |
| 10 引擎选型 | 什么时候换引擎？ | 两种引擎的能力与限制比较 | 选型决策图 |
| 11 稳定服务 | 如何长时间可用？ | 健康检查、日志、超时、恢复 | 服务架构图 |
| 12 完整交付 | 如何从约束设计系统？ | 部署包、复现清单、测评报告 | 端到端体系图 |

### 路径划分

- 通用必修 00—06：优先选择 CPU/MPS/CUDA 都有机会跑通的方案。
- 可选性能分支 07—10：严格按引擎支持与真实 GPU 条件决定是否实验；有条件再使用 vLLM / SGLang。
- 完整工程 11—12：提供可组合参考架构；不能把只在云端跑通的实验标成 Mac 本机 PASS。

每章默认结构：**问题 → 能力目标 → 先看图 → 5 分钟动手 → 原理解读 → 延伸实验 → 验证记录 → 常见故障 → 小结**。以真正能做成事情为优先。
