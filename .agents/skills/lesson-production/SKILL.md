description: Produce one verified chapter of the Inference practice book using real experiments, Chinese explanations, and minimal tests. Use when drafting or updating a chapter.
---

1. Read `plan/LESSON_STANDARD.md` and relevant section in `plan/CONTENTS.md`.
2. Choose the smallest runnable experiment; check environment and permissions.
3. Write code in `experiments/chXX/`; run it; keep truthful status/evidence.
4. Write `docs/chapters/chXX.md` based on actual observed behavior, not invented output.
5. Add useful diagram, table, or interactive element where it materially clarifies a concept.
6. Check links, build site, and explicitly label anything not yet tested.
7. Return exact commands, PASS/FAIL/BLOCKED and the chapter preview path.
