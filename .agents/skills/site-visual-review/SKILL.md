---
name: site-visual-review
description: Review VitePress chapter pages and interactive figures visually in desktop and mobile browser. Use when polishing front-end pages or diagrams.
---

1. Start site preview with `npm run docs:dev`.
2. If Codex browser / computer use / Playwright is available, inspect homepage, chapter, and TokenStepper at desktop and mobile widths.
3. Check layout, contrast, mixed Chinese/English typography, code overflow, navigation, keyboard controls, alt text, and interactive behavior.
4. Fix actual issues, then run `npm run docs:build` and recheck key screens.
5. Do not claim screenshots or browser review were performed if browser access was unavailable; state limitations.
