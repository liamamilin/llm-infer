# 从这里开始

这是一本面向实践的 Inference 工程书。目标不是研究新的 Attention 算法，而是学会使用成熟工具运行、部署、测试、优化大模型。

## 学习路径

1. **第 00—04 章：让模型跑起来**。检查环境、模型文件、生成过程、推理 API 和 Streaming。
2. **第 05—06 章：知道瓶颈在哪里**。测量首 Token 延迟、生成速度与内存。
3. **第 07—10 章：使用现成优化工具**。量化、前缀缓存、并发与引擎选型。
4. **第 11—12 章：把模型交付成服务**。探针、准入控制、超时、日志、崩溃恢复，以及最后的评估报告与洁净室复现。

## 如何使用本书

- 阅读章节概念，再运行该章 `experiments/chXX/` 的代码。
- 每个实验都记录执行环境和模型版本，不把小模型的指标推论成大模型的硬件表现。
- 如果你使用的是 CPU 或 Apple Silicon，不必一开始追逐 CUDA 专用部署方案。

全部 13 章（第 00—12 章）已完成并实测。从 [第 00 章](/chapters/ch00) 开始。
